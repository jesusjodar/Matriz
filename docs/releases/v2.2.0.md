# Matriz 2.2.0 · Color orgánico, agentes de IA y Wallpaper

## Novedades

- **Color más orgánico.** La paleta sigue el relieve de las ondas con una distribución más irregular y un nuevo control de blur del ruido de color.
- **Luces y sombras más equilibradas.** Nuevo control para iluminar las zonas profundas y una curva de brillo que reduce las altas luces quemadas y las bandas duras.
- **Partículas más expresivas.** Arrastre suave alrededor de las zonas luminosas y concavidad gradual ligada al tamaño: las partículas pequeñas son más cóncavas y las grandes, más abiertas.
- **Más respuesta a la música.** Bajos y agudos tienen mayor presencia e influyen en las ondas superior e inferior, la anchura de la onda central y el tamaño y la irregularidad de los orbes.
- **Carátulas más fieles.** La extracción conserva mejor los colores dominantes, los acentos, los pasteles y los tonos de portadas monocromas o en escala de grises.
- **Ajustes rediseñados.** Fondo negro puro, navegación superior Liquid Glass en sistemas compatibles, grupos en paneles y líneas de color bajo el matiz y la paleta activa. Interfaz disponible en 20 idiomas.
- **Colores según el estado de tus agentes.** Nueva sección para Codex, Claude Code, OpenCode, Hermes, LM Studio y otros agentes: reposo, ejecución, permisos, respuesta humana, error y finalización. Incluye conectores locales, transiciones suaves y prioridad entre sesiones simultáneas, sin guardar conversaciones.
- **Extensión de Wallpaper.** Matriz aparece como fondo elegible en Ajustes del Sistema y ofrece su shader al escritorio, al bloqueo de la sesión y al salvapantallas. El módulo `Matriz.saver` independiente continúa incluido.

**Se conservan los ajustes existentes.** Los colores de agentes se activan de forma opcional y requieren conectar los hooks o el cliente correspondiente. Consulta la [guía de agentes](https://github.com/jesusjodar/Matriz/blob/v2.2.0/integrations/README.md): LM Studio observa las peticiones del cliente API conectado, no todos los chats de su app.

## Requisitos y compatibilidad

- ZIP compilado para **Apple Silicon (arm64)**. En Intel, compila desde el código fuente.
- App y módulo de salvapantallas: **macOS 14+**. Audio reactivo: **macOS 14.2+**. Extensión de Wallpaper: **macOS 26+**.
- La extensión utiliza API privada de macOS y puede necesitar ajustes tras una actualización del sistema. Se ha comprobado su registro y su aparición en el selector de fondos en macOS 27.2; queda pendiente probar el ciclo físico de bloqueo y desbloqueo. No cambia la contraseña ni FileVault.
- La música y las carátulas se procesan en la app de escritorio. Los colores de agentes también pueden llegar a la extensión mediante los conectores.
- Firma local, **sin notarización de Apple**. Retira la cuarentena únicamente del paquete descargado de esta release, después de verificar su SHA-256.

## Descargar y verificar

Ejecuta estos comandos en una carpeta vacía:

```sh
curl --fail --location --output Matriz-2.2.0.zip \
  https://github.com/jesusjodar/Matriz/releases/download/v2.2.0/Matriz-2.2.0.zip
curl --fail --location --output SHA256SUMS \
  https://github.com/jesusjodar/Matriz/releases/download/v2.2.0/SHA256SUMS
shasum -a 256 -c SHA256SUMS
```

El resultado debe ser `Matriz-2.2.0.zip: OK`.

**SHA-256 de `Matriz-2.2.0.zip`:**

```text
026a3d3df7bd808b000f59fbfddb00c0dd09fbf62bdc5383d824dd13facc762a
```

## Instalar o actualizar y retirar la cuarentena

Después de verificar la descarga, ejecuta este bloque en la misma carpeta. Guarda la instalación anterior como copia de seguridad y conserva las preferencias de Matriz.

```sh
(
set -e
unzip -q Matriz-2.2.0.zip
xattr -dr com.apple.quarantine Matriz.app Matriz.saver
pkill -x Matriz 2>/dev/null || true
MATRIZ_BACKUP_DIR="$HOME/Library/Application Support/Matriz/Backups/update-$(date +%Y%m%d-%H%M%S)"
mkdir -p "$HOME/Applications" "$HOME/Library/Screen Savers" "$MATRIZ_BACKUP_DIR"
if [ -d "$HOME/Applications/Matriz.app" ]; then
  mv "$HOME/Applications/Matriz.app" "$MATRIZ_BACKUP_DIR/Matriz.app"
fi
if [ -d "$HOME/Library/Screen Savers/Matriz.saver" ]; then
  mv "$HOME/Library/Screen Savers/Matriz.saver" "$MATRIZ_BACKUP_DIR/Matriz.saver"
fi
ditto Matriz.app "$HOME/Applications/Matriz.app"
ditto Matriz.saver "$HOME/Library/Screen Savers/Matriz.saver"
open "$HOME/Applications/Matriz.app"
)
```

Para elegir la extensión, abre **Ajustes del Sistema → Fondo de pantalla → Matriz**. En **Salvapantallas…** puedes elegirla para el reposo. La selección del fondo del sistema permanece activa aunque cierres Matriz; para retirarla, elige otro fondo.

## Comprobaciones

Pruebas de animación web, traducciones, conectores, shader Metal, audio sintético, extracción de color, preferencias entre procesos, carga del salvapantallas y contexto remoto de Wallpaper superadas. Las conexiones reales con cada agente y el ciclo físico de bloqueo/desbloqueo no forman parte de estas pruebas automatizadas.
