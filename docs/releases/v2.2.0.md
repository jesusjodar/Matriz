# Matriz 2.2.0 · Organic color, AI agents and Wallpaper

## What's new

- **More organic color.** The palette follows the wave relief with a more irregular distribution and a new color noise blur control.
- **Better balanced light and shadows.** A new control brightens deep areas, while a brightness curve reduces blown highlights and harsh bands.
- **More expressive particles.** Gentle drift around bright areas and gradual size-based concavity: smaller particles are more concave and larger ones are more open.
- **Stronger music response.** Bass and treble have more presence, affecting upper and lower waves, center-wave width, and orb size and irregularity.
- **More faithful artwork colors.** Extraction better preserves dominant colors, accents, pastels and tones in monochrome or grayscale covers.
- **Redesigned settings.** Pure black background, Liquid Glass top navigation on supported systems, grouped panels and color strips beneath hue and the active palette. Interface available in 20 languages.
- **Colors that follow your agents' states.** A new section for Codex, Claude Code, OpenCode, Hermes, LM Studio and other agents: idle, running, permission, human input, error and completion. Includes local connectors, smooth transitions and priority across concurrent sessions without storing conversations.
- **Wallpaper extension.** Matriz appears as a selectable wallpaper in System Settings and supplies its shader to the desktop, session lock screen and screensaver. The standalone `Matriz.saver` module remains included.

**Existing settings are preserved.** Agent colors are optional and require connecting the corresponding hooks or client. See the English [agent guide](https://github.com/jesusjodar/Matriz/blob/main/integrations/README.md): LM Studio observes requests from the connected API client, not every chat in its app.

## Requirements and compatibility

- ZIP built for **Apple Silicon (arm64)**. On Intel, build from source.
- App and screensaver module: **macOS 14+**. Audio response: **macOS 14.2+**. Wallpaper extension: **macOS 26+**.
- The extension uses a private macOS API and may need adjustments after system updates. Registration and appearance in the wallpaper picker were checked on macOS 27.2; the physical lock/unlock cycle remains untested. Passwords and FileVault are unchanged.
- Music and artwork are processed in the desktop app. Agent colors can also reach the extension through connectors.
- Local signing, **without Apple notarization**. Remove quarantine only from the package downloaded from this release, after verifying its SHA-256.

## Install or update and remove quarantine

After verifying the download, run this block in the same folder. It backs up the previous installation and preserves Matriz preferences.

```sh
(
set -e
unzip -q Matriz-2.2.0.zip
xattr -dr com.apple.quarantine Matriz.app Matriz.saver
pkill -x Matriz 2>/dev/null || true
MATRIZ_BACKUP_DIR="$HOME/Library/Application Support/Matriz/Backups/update-$(date +%Y%m%d-%H%M%S)"
mkdir -p "$HOME/Applications" "$HOME/Library/Screen Savers" "$MATRIZ_BACKUP_DIR"
if [ -d "$HOME/Applications/Matriz.app" ]; then
  mv "$HOME/Applications/Matriz.app" "$MATRIZ_BACKUP_DIR/Matriz.app"
fi
if [ -d "$HOME/Library/Screen Savers/Matriz.saver" ]; then
  mv "$HOME/Library/Screen Savers/Matriz.saver" "$MATRIZ_BACKUP_DIR/Matriz.saver"
fi
ditto Matriz.app "$HOME/Applications/Matriz.app"
ditto Matriz.saver "$HOME/Library/Screen Savers/Matriz.saver"
open "$HOME/Applications/Matriz.app"
)
```

To choose the extension, open **System Settings → Wallpaper → Matriz**. Select it under **Screen Saver…** for idle use. The system wallpaper selection remains active after quitting Matriz; choose another wallpaper to remove it.

Web animation, translations, connectors, Metal shader, synthetic audio, color extraction, cross-process preferences, screensaver loading and remote Wallpaper context checks passed. Live connections with each agent and the physical lock/unlock cycle are outside these automated tests.
