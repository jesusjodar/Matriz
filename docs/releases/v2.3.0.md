# Matriz 2.3.0 · Windows and web backgrounds

## What's new

- **Matriz for Windows.** Portable x64 and ARM64 packages with native WinUI 3 settings, top navigation, grouped controls and local preferences. The background uses WebView2 behind Explorer desktop icons.
- **A component ready for your website.** Includes `<matriz-background>`, a canvas API, TypeScript types, ESM, a classic script and an example. **No AI, music or visible settings:** values are configured directly in code. Respects Reduce Motion, pauses when out of view and releases resources when unmounted.
- **The same look across all three platforms.** A shared shader and a tested contract for values and limits keep waves, palettes, shadows, color noise, displacement and concavity consistent. Fixes a reserved GLSL word that prevented WebGL2 compilation.
- **Desktop app integrations.** Windows adds microphone-free WASAPI loopback capture, colors from artwork published by media players and local connectors for agent states. These are optional and excluded from the web package.
- **Settings preserved.** Existing macOS preferences are not reset. Windows keeps separate settings and preserves a backup when recovering an invalid file.

This version retains the organic color, protected highlights, particle, music and Wallpaper improvements introduced in [2.2.0](https://github.com/jesusjodar/Matriz/releases/tag/v2.2.0).

## Download and verify on macOS

```sh
curl --fail --location --output Matriz-macOS-arm64-2.3.0.zip \
  https://github.com/jesusjodar/Matriz/releases/download/v2.3.0/Matriz-macOS-arm64-2.3.0.zip
curl --fail --location --output SHA256SUMS \
  https://github.com/jesusjodar/Matriz/releases/download/v2.3.0/SHA256SUMS
shasum -a 256 -c SHA256SUMS --ignore-missing
```

`SHA256SUMS` includes SHA-256 hashes for all five packages. `--ignore-missing` checks the files you downloaded.

SHA-256 of `Matriz-macOS-arm64-2.3.0.zip`: `e3eed67d35919266bf96874aefe633913e072b33ca4a32c99bba7cbd4067aa8a`.

## Install or update and remove quarantine on macOS

After verifying the download, run this block in the same folder. It backs up the previous installation and preserves Matriz preferences.

```sh
(
set -e
unzip -q Matriz-macOS-arm64-2.3.0.zip
xattr -dr com.apple.quarantine Matriz.app Matriz.saver
pkill -x Matriz 2>/dev/null || true
MATRIZ_BACKUP_DIR="$HOME/Library/Application Support/Matriz/Backups/update-$(date +%Y%m%d-%H%M%S)"
mkdir -p "$HOME/Applications" "$HOME/Library/Screen Savers" "$MATRIZ_BACKUP_DIR"
if [ -d "$HOME/Applications/Matriz.app" ]; then
  mv "$HOME/Applications/Matriz.app" "$MATRIZ_BACKUP_DIR/Matriz.app"
fi
if [ -d "$HOME/Library/Screen Savers/Matriz.saver" ]; then
  mv "$HOME/Library/Screen Savers/Matriz.saver" "$MATRIZ_BACKUP_DIR/Matriz.saver"
fi
ditto Matriz.app "$HOME/Applications/Matriz.app"
ditto Matriz.saver "$HOME/Library/Screen Savers/Matriz.saver"
open "$HOME/Applications/Matriz.app"
)
```

To choose the extension, open **System Settings → Wallpaper → Matriz**. Select it under **Screen Saver…** for idle use. The system wallpaper selection remains active after quitting Matriz; choose another wallpaper to remove it.

## Windows

Download the ZIP for your architecture from this release and compare its hash against `SHA256SUMS`:

```powershell
Get-FileHash .\Matriz-Windows-x64.zip -Algorithm SHA256
Expand-Archive .\Matriz-Windows-x64.zip -DestinationPath .\Matriz
.\Matriz\Matriz.exe
```

For ARM64, substitute the ZIP name. Keep all extracted files together. When updating, close Matriz before replacing files and preserve `%LOCALAPPDATA%\Matriz`. The app has no commercial signature and Windows may show SmartScreen. Requires [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/).

## Integrate into a website

Extract `Matriz-Web-2.3.0.zip`, serve the folder over HTTP and open `example.html`. Its code shows configurable values without adding controls. For an npm project:

```sh
npm install ./matriz-background-2.3.0.tgz
```

```html
<section style="position:relative; min-height:500px; background:#000">
  <matriz-background settings='{"palette":5,"speed":0.7,"colorBlur":0.65}'></matriz-background>
  <h1 style="position:relative">Your content</h1>
</section>
<script type="module" src="./dist/matriz-background.js"></script>
```

## Validation and limitations

- Shared tests, web package installation with types and actual WebGL2 rendering passed. Checks cover independent instances, context recovery, absence of music and AI APIs on the web, and Windows adapter palettes.
- macOS, Windows x64 and ARM64 builds checked in CI; native self-test run on Windows x64. On the Mac, checks cover Metal, synthetic audio, preferences, screensaver and Wallpaper without replacing the installed app or changing its settings.
- Physical checks of the Windows desktop, audio devices and media players remain pending; ARM64 is built but has not run on ARM hardware. WorkerW is undocumented Explorer behavior and may change. Windows includes no `.scr` screensaver or animated lock screen.
- macOS retains local signing without notarization and a Wallpaper extension using a private API. The physical lock/unlock cycle remains untested. Passwords and FileVault are unchanged.
