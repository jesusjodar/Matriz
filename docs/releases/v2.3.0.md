# Matriz 2.3.0 · Windows y fondo web

## Novedades

- **Matriz para Windows.** Paquetes portables x64 y ARM64 con ajustes nativos WinUI 3, navegación superior, grupos de controles y preferencias locales. El fondo usa WebView2 detrás de los iconos del escritorio de Explorer.
- **Un componente listo para tu web.** Incluye `<matriz-background>`, API de canvas, tipos TypeScript, ESM, script clásico y un ejemplo. **Sin IA, música ni ajustes visibles:** los valores se configuran directamente en el código. Respeta Reducir movimiento, pausa cuando no se ve y libera recursos al desmontarse.
- **El mismo aspecto en las tres plataformas.** Un shader común y un contrato comprobado de valores y límites mantienen ondas, paletas, sombras, ruido de color, desplazamiento y concavidad coherentes. Se corrige una palabra reservada de GLSL que impedía compilar en WebGL2.
- **Integraciones en las apps de escritorio.** Windows incorpora captura WASAPI loopback sin micrófono, colores de carátulas publicadas por los reproductores y conectores locales para estados de agentes. Son opcionales y quedan fuera del paquete web.
- **Ajustes conservados.** No se restablecen las preferencias existentes de macOS. Windows mantiene su configuración separada y preserva una copia si necesita recuperar un archivo inválido.

Esta versión conserva las mejoras de color orgánico, luces protegidas, partículas, música y Wallpaper introducidas en [2.2.0](https://github.com/jesusjodar/Matriz/releases/tag/v2.2.0).

## Descargar y verificar en macOS

```sh
curl --fail --location --output Matriz-macOS-arm64-2.3.0.zip \
  https://github.com/jesusjodar/Matriz/releases/download/v2.3.0/Matriz-macOS-arm64-2.3.0.zip
curl --fail --location --output SHA256SUMS \
  https://github.com/jesusjodar/Matriz/releases/download/v2.3.0/SHA256SUMS
shasum -a 256 -c SHA256SUMS --ignore-missing
```

`SHA256SUMS` incluye los hashes SHA-256 de los cinco paquetes. `--ignore-missing` comprueba los archivos que hayas descargado.

SHA-256 de `Matriz-macOS-arm64-2.3.0.zip`: `e3eed67d35919266bf96874aefe633913e072b33ca4a32c99bba7cbd4067aa8a`.

## Instalar o actualizar y retirar la cuarentena en macOS


Después de verificar la descarga, ejecuta este bloque en la misma carpeta. Guarda la instalación anterior como copia de seguridad y conserva las preferencias de Matriz.

```sh
(
set -e
unzip -q Matriz-macOS-arm64-2.3.0.zip
xattr -dr com.apple.quarantine Matriz.app Matriz.saver
pkill -x Matriz 2>/dev/null || true
MATRIZ_BACKUP_DIR="$HOME/Library/Application Support/Matriz/Backups/update-$(date +%Y%m%d-%H%M%S)"
mkdir -p "$HOME/Applications" "$HOME/Library/Screen Savers" "$MATRIZ_BACKUP_DIR"
if [ -d "$HOME/Applications/Matriz.app" ]; then
  mv "$HOME/Applications/Matriz.app" "$MATRIZ_BACKUP_DIR/Matriz.app"
fi
if [ -d "$HOME/Library/Screen Savers/Matriz.saver" ]; then
  mv "$HOME/Library/Screen Savers/Matriz.saver" "$MATRIZ_BACKUP_DIR/Matriz.saver"
fi
ditto Matriz.app "$HOME/Applications/Matriz.app"
ditto Matriz.saver "$HOME/Library/Screen Savers/Matriz.saver"
open "$HOME/Applications/Matriz.app"
)
```

Para elegir la extensión, abre **Ajustes del Sistema → Fondo de pantalla → Matriz**. En **Salvapantallas…** puedes elegirla para el reposo. La selección del fondo del sistema permanece activa aunque cierres Matriz; para retirarla, elige otro fondo.


## Windows

Descarga el ZIP de tu arquitectura desde esta release y compara su hash con `SHA256SUMS`:

```powershell
Get-FileHash .\Matriz-Windows-x64.zip -Algorithm SHA256
Expand-Archive .\Matriz-Windows-x64.zip -DestinationPath .\Matriz
.\Matriz\Matriz.exe
```

Para ARM64 sustituye el nombre del ZIP. Mantén todos los archivos extraídos juntos. Al actualizar, cierra Matriz antes de sustituirlos y conserva `%LOCALAPPDATA%\Matriz`. La app no tiene firma comercial y Windows puede mostrar SmartScreen. Requiere [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/).

## Integrar en una web

Extrae `Matriz-Web-2.3.0.zip`, sirve la carpeta por HTTP y abre `example.html`. Su código muestra los valores configurables; no añade controles. Para un proyecto con npm:

```sh
npm install ./matriz-background-2.3.0.tgz
```

```html
<section style="position:relative; min-height:500px; background:#000">
  <matriz-background settings='{"palette":5,"speed":0.7,"colorBlur":0.65}'></matriz-background>
  <h1 style="position:relative">Tu contenido</h1>
</section>
<script type="module" src="./dist/matriz-background.js"></script>
```

## Comprobaciones y límites

- Pruebas compartidas, instalación del paquete web con sus tipos y renderizado WebGL2 real superados. Se comprueban instancias independientes, recuperación del contexto, ausencia de APIs de música e IA en la web y las paletas del adaptador de Windows.
- Compilaciones de macOS, Windows x64 y ARM64 comprobadas en CI; autocomprobación nativa ejecutada en Windows x64. En el Mac se comprueban Metal, audio sintético, preferencias, salvapantallas y Wallpaper sin sustituir la app instalada ni cambiar su configuración.
- Falta la prueba física del escritorio, dispositivos de audio y reproductores de Windows; ARM64 se compila pero no se ejecuta en hardware ARM. WorkerW es un comportamiento no documentado de Explorer que puede cambiar. Windows no incluye `.scr` ni fondo animado de bloqueo.
- En macOS se mantiene la firma local sin notarización y la extensión Wallpaper con API privada. El ciclo físico de bloqueo/desbloqueo sigue pendiente. No se cambia la contraseña ni FileVault.
